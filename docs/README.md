# Documentation PFM - Diagrams

1. Dans VS Code avec l'extension [Mermaid Preview](https://marketplace.visualstudio.com/items?itemName=bierner.markdown-mermaid)

3. En ligne sur [Mermaid Live Editor](https://mermaid.live/)
